# Biz365

Premium NFC and QR-enabled business growth products, including Google Review stands, cards, stickers, plates, and bundles.

## Current status

Phase 1 establishes the premium storefront foundation, responsive navigation, product-led homepage, typed catalog architecture, reusable product visuals, and SEO foundations.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React
- Vinext / Vite compatibility for ChatGPT Sites

## Product principle

Biz365 products make a business destination available through either an NFC tap or QR scan. The initial catalog uses standard Biz365 products without a customer-facing visual customizer.
